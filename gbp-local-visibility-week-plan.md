## 1. Category strategy for generic dentist discovery

> **Keep `Dentist` as the primary category.** It is the clearest accurate primary category for generic `dentist near me` and `dentist Garden Grove` intent. Google says that categories should describe what the business *is*, rather than trying to target keywords; adding unnecessary categories is not a generic-ranking tactic.[1]

| Category status | Current finding | Action |
|---|---|---|
| Primary category | `Dentist` | **Keep.** Do not replace with `Dental clinic`, `Cosmetic dentist`, or `Orthodontist`; doing so would weaken the main general-dentist entity signal. |
| Existing secondary categories | Endodontist, Orthodontist, Periodontist, Dental clinic, Cosmetic dentist, Pediatric dentist, Teeth whitening service, Emergency dental service | **Keep only where services are ongoing and represented by the practice.** These accurately express Uplift’s multi-specialty scope. |
| Possible `Family dentist` addition | Not currently observed | Add only if the practice confirms it routinely provides general dental care to both children and adults under that service positioning. Do not add merely for rank chasing. |
| Possible `Oral surgeon` addition | Oral surgery availability is represented in the practice description, but this category was not observed in the editor list | Add only if an oral surgeon is regularly available through the practice and Uplift can truthfully present itself this way. |

The generic-rank opportunity is not a primary-category swap. It is stronger **service completeness, local entity consistency, authentic profile content, and ongoing activity** around an already correct primary `Dentist` category.
