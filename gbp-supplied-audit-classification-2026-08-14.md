## Why the HTTP Correction Should Be First

The Website action is an explicit field on the public profile and its current HTTP value is a verified factual mismatch. The HTTPS target is the current canonical public homepage and requires no marketing claim or judgment. This is therefore the only immediate GBP correction recommended before the service editor and hours fields are re-verified.

> Google describes local results as primarily based on relevance, distance, and prominence. A corrected URL improves consistency but does not by itself guarantee a map-ranking change. The proper measurement is a repeat of the same grid configuration.[1]

Each needs an exact source, appropriate consent where people or treatment outcomes appear, and factual wording. Likewise, the public recommendation cards for photos and hours are not proof that prior approved submissions failed.
